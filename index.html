    📊 Order log (Google Sheet)

    Every order sent from any customer's phone is added as a row in your Google Sheet. Free, takes about 5 minutes to set up.

    How to set it up
    1. Create a new Google Sheet (sheets.new).
    2. Open Extensions → Apps Script.
    3. Delete the code there, paste the code below, and click Save.
    4. Click Deploy → New deployment, choose type Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and allow access.
    5. Copy the Web app URL (ends in /exec), paste it above, and tap Save changes.
    6. Tap Send test row and check the sheet's “Orders” tab.
